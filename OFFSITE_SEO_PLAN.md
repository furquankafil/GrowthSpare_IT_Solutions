# Off-site SEO Plan — GrowthSpare IT Solutions (white-hat only)

**Current state:** No backlinks claimed or built by prior work. No spam links found in code (no hidden links, no injected anchors; footer social links are `rel=noopener noreferrer`, client links `rel=nofollow` where external). Domain authority must be earned. No rankings guaranteed.

## Principles

- Never buy links, never join link farms/PBNs, never auto-submit to spam directories.
- Every listing must use the exact NAP from `/contact/` (see LOCAL_SEO_AUDIT.md).
- One profile per platform; complete it fully (logo, hours, services, site link) or skip it.

## Phase 1 — Foundations (week 1–2, owner, ~4h)

1. Google Business Profile (see LOCAL_SEO_AUDIT.md) — the single highest-ROI off-site action for Delhi NCR queries.
2. Bing Places + Apple Business Connect (same NAP; 30 min each).
3. Core Indian directories (genuine, moderated): JustDial, IndiaMART, Sulekha, Clutch India, GoodFirms, DesignRush (IT listings). Only where a real company profile fits; skip paid "featured" upsells initially.
4. Social proof of existence: LinkedIn Company (exists — link already in footer), Instagram/Facebook (exist), GitHub org (exists as personal link; consider company org later), Crunchbase (free stub).

## Phase 2 — Relevance (week 3–4, ~3h)

5. Developer-community presence (no link begging): GitHub repo READMEs linking back to relevant service pages where genuinely useful (e.g. Django/WhatsApp starter → `/services/ai-whatsapp-automation/`), Stack Overflow / Dev.to answers disclosing affiliation.
6. Partner/case-study links: for each real deployment (e.g. Elevate Workforce), ask the client for a "Built by GrowthSpare" footer link to the matching portfolio page. Only real clients, only with permission.
7. Supplier/tools pages: if using Razorpay/PhonePe/WhatsApp Cloud API partner directories, apply for partner listings.

## Phase 3 — Authority content (month 2+, 2h/week)

8. Original resources worth linking to (build ONE before outreach):
   - `Website Development Cost in Delhi (2026 Guide)` — already published as blog; expand with anonymised real quote ranges from GrowthSpare's own pipeline (no competitor fabrication).
   - `Technical SEO Checklist for Business Websites` — already published; add downloadable PDF checklist (gated by newsletter, not paywalled).
9. Digital PR (local, honest): pitch Delhi/NCR SME publications on "what small businesses overpay for websites" using the cost guide as source. No press-release spam.
10. Guest contributions: ONE in-depth post/quarter on a reputable Indian startup/SME blog (founder byline, genuine advice, single natural bio link). Quality over volume.

## What NOT to do

- No directory blasts (>50 submissions), no footer-link exchanges, no "guest post for $X" offers, no fake reviews on GBP/Clutch/JustDial, no exact-match anchor spam.
- Disavow file: not needed (no toxic links known). Revisit only if Search Console reports manual action.

## Measurement (monthly, Search Console only)

- Links → Top linking sites (expect directories first, then clients/press).
- Performance → queries containing Delhi/Noida/Gurgaon + website/web developer/design.
- Do not chase Domain Authority scores; track indexed pages, impressions on commercial/local terms, and audit-request conversions in GA4.
