## Case-study template (for real engagements only)

1. Project + client (named only with permission) + industry + live URL.
2. Business problem (their words where possible).
3. Requirements (scope list, timeline band).
4. Solution + design decisions (why this structure/stack).
5. Technologies (exact).
6. Challenges + implementation notes (honest, including tradeoffs).
7. Screenshots (real product, desktop + mobile).
8. Outcome: measured numbers ONLY with methodology + timeframe (e.g. "audit requests via Search Console/GA4, Mar–May 2026"); otherwise a scope-delivered statement like the two verified projects use.
